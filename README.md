# بطاقة مزايا لطف

نسخة تجريبية خاصة ذات ثلاث واجهات عربية، مبنية بـ React وVinext وCloudflare D1.

## ما يعمل
- بيانات مستفيدين وشركاء وفروع وعروض محفوظة في D1 لكل حساب تجربة.
- إصدار QR عشوائي، إيقاف وتجديد البطاقة واستبدال رمزها.
- تحقق مباشر قبل العرض، وفحص الصلاحية والحدود مرة أخرى عند التأكيد.
- تأكيد العمليات بمعرّف يمنع تكرار الطلب، وتحكم متفائل بالإصدارات يمنع تجاوز الحدود بالتزامن.
- إلغاء بسبب محفوظ، ومفضلة، وتقارير Excel، وتنزيل بطاقة PDF وطباعة.
- حدود مفتوحة، وحد طوال مدة العرض، وحد شهري، وفترة متحركة.

## حدود النسخة الحالية
هذه ليست نسخة إطلاق عام. الواجهات الثلاث أوضاع معاينة لصاحب حساب التجربة، وليست حدود صلاحيات إنتاجية. البيانات في وثيقة واحدة لكل صاحب تجربة، وهو تصميم مناسب للتجربة ويحتاج تحويلًا لجداول علائقية وفهارس قبل التوسع. لا تدخل بيانات حقيقية أو حساسة في هذه النسخة.
- لم ينفذ تسجيل مستفيد بالجوال، ولا حسابات شركاء وموظفين منفصلة، ولا طلبات أهلية عامة أو استيراد Excel.
- لا تزال إدارة أدوار الموظفين والتحديث الكامل للعروض والفروع ضمن العمل المتبقي.
- زر Apple Wallet يعرض متطلبات التفعيل فقط؛ لا يصدر ملف pkpass ولا يحدث المحفظة. يتطلب تنفيذ خدمة توقيع وتحديث وربط شهادة Apple واختبارها.
- لم يختبر المسح باستخدام كاميرا هاتف فعلية بعد.
- النسخة خاصة بصاحب المشروع؛ لا تغيّر المشاركة إلى عامة قبل إضافة صلاحيات الخادم وحسابات الإنتاج.

## التشغيل
Node 22 أو أحدث وpnpm 11.19.0.
1. pnpm install
2. pnpm build
3. تطبيق ملفات drizzle على قاعدة D1 المحلية باستخدام wrangler مع dist/server/wrangler.json.
4. pnpm dev
5. الدخول المحلي التجريبي عبر /signin-with-chatgpt?return_to=/؛ لا يستخدم حسابًا حقيقيًا.

## التحقق
اجتاز TypeScript وبناء Worker. تم اختبار قواعد الأهلية والحدود والإلغاء، واختبار API فعلي محلي: التكرار المتزامن، التحقق بلا استهلاك، الإيقاف، استبدال الرمز ورفض الدخول المجهول.

## تسليم وتشغيل فعلي
الحسابات الخارجية المطلوبة: Apple Developer باسم الجهة، مزود SMS، ومزود دخول عام معتمد. لا توجد مفاتيح أو شهادات في المصدر. يلزم قبل الإطلاق تنفيذ RBAC وتحديد أهلية العضوية، فصل قاعدة البيانات وتطبيق تدقيق وصلاحيات الشركاء على الخادم، واختبار أمان وحمل واستعادة النسخ الاحتياطية.
